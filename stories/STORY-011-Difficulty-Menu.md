# STORY-011-Difficulty-Menu

## Description
Implement the UI component that allows players to select between Beginner, Intermediate, Expert, and Custom difficulty levels.

## Acceptance Criteria
- [ ] Difficulty menu displays all four options: Beginner, Intermediate, Expert, Custom
- [ ] Selecting a difficulty preset initializes a new game with those settings
- [ ] Selecting Custom reveals the custom difficulty input fields
- [ ] Current difficulty is visually indicated in the menu
- [ ] Switching difficulties mid-game prompts to confirm or auto-starts a new game
- [ ] Menu is accessible and easy to use

## Tasks
- [ ] Create difficulty selection UI (dropdown menu or button group)
- [ ] Implement preset selection handlers
- [ ] Implement Custom mode toggle to show/hide custom input fields
- [ ] Wire difficulty selection to game initialization
- [ ] Add visual indicator for currently selected difficulty
- [ ] Add mid-game difficulty switch confirmation (or auto-reset)
- [ ] Test all difficulty transitions

## Dependencies
- STORY-003-Difficulty-Presets, STORY-004-Custom-Difficulty
