# STORY-011-Difficulty-Menu

## Description
Implement the UI component that allows players to select between Beginner, Intermediate, Expert, and Custom difficulty levels.

## Acceptance Criteria
- [x] Difficulty menu displays all four options: Beginner, Intermediate, Expert, Custom
- [x] Selecting a difficulty preset initializes a new game with those settings
- [x] Selecting Custom reveals the custom difficulty input fields
- [x] Current difficulty is visually indicated in the menu
- [x] Switching difficulties mid-game prompts to confirm or auto-starts a new game
- [x] Menu is accessible and easy to use

## Tasks
- [x] Create difficulty selection UI (dropdown menu or button group)
- [x] Implement preset selection handlers
- [x] Implement Custom mode toggle to show/hide custom input fields
- [x] Wire difficulty selection to game initialization
- [x] Add visual indicator for currently selected difficulty
- [x] Add mid-game difficulty switch confirmation (or auto-reset)
- [x] Test all difficulty transitions

## Dependencies
- STORY-003-Difficulty-Presets, STORY-004-Custom-Difficulty
